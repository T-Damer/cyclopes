# Description

Cyclopes helps you identify AI-generated images while browsing the web.
It analyzes eligible images locally using an embedded AI model—images are never uploaded to a server.

Features:
- Private, on-device AI image detection
- Clear confidence badges displayed over images
- Works across social networks, galleries, and other websites
- Per-site controls and an exclusion list
- Adjustable detection threshold and minimum image size
- Optional local correction reports for false positives and false negatives
- No account, subscription, or remote inference required

AI-image detection is probabilistic and may occasionally produce incorrect results, especially for compressed images, memes, screenshots, and heavily edited artwork. Cyclopes is intended as a helpful signal, not definitive proof of an image’s origin.
