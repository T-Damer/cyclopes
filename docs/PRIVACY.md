# Cyclopes privacy policy

Last updated: August 15, 2026.

Cyclopes processes visible webpage images locally to estimate whether they are AI-generated. Images, URLs, browsing activity, and inference results are not sent to Cyclopes, its developers, or third parties.

The extension stores settings, excluded sites, and optional user-created reports in browser-local storage. A report contains the user's AI/non-AI label, the local model score, source-page context, and a compressed 256 px WebP preview. This data remains on the device and is used only for the extension's user-facing features. Users can delete reports in the extension or remove all stored data by uninstalling it.

Cyclopes does not sell data, serve advertising, run analytics, or allow humans to inspect user data. Its use of browser data is limited to providing the extension's disclosed image-detection features.

Questions can be filed in the [Cyclopes issue tracker](https://github.com/T-Damer/cyclopes/issues).
